# API Token
An API token is the bearer credential `myrasec.NewWithToken` takes (see [Setup](./setup.md)). It carries the permissions of the user that created it. Unlike an [API key](./apikey.md) a token can be disabled and it can carry an expiry date. The functions below manage the tokens of the authenticated user only.

```go
type APIToken struct {
    ID           int             `json:"id,omitempty"`
    Created      *types.DateTime `json:"created,omitempty"`
    Modified     *types.DateTime `json:"modified,omitempty"`
    Name         string          `json:"name,omitempty"`
    Enabled      bool            `json:"enabled"`
    ExpiryDate   *types.DateTime `json:"expiryDate,omitempty"`
    LastUsedDate *types.DateTime `json:"lastUsedDate,omitempty"`
    Token        string          `json:"token,omitempty"`
}
```
| Field | Type | Description|
|---|---|---|
| `ID` | int | ID is a unique identifier for an object. This value is always a number type and cannot be set while inserting a new object. To update or delete an API token it is necessary to add this attribute to your object. |
| `Created` | *types.DateTime | Created is a date type attribute with an `ISO 8601` format. Created will be created by the server after creating a new API token object. This value is informational so it is not necessary to add this attribute to any API call. |
| `Modified` | *types.DateTime | Identifies the version of the object. To ensure that you are updating the most recent version and not overwriting other changes, you always have to add modified for updates. This value is always a date type with an `ISO 8601` format. |
| `Name` | string | An arbitrary name of the API token. Required. The API reserves one name for internal use: creating a token with it and updating a token that carries it are rejected with `400 Bad Request`, the violation names it. |
| `Enabled` | bool | Whether the token can be used for authentication. A disabled token is rejected with `403 Forbidden`. The flag is always sent, so set it to `true` when creating or updating a token. |
| `ExpiryDate` | *types.DateTime | Optional point in time after which the token is rejected with `403 Forbidden`. The API validates it against the start of the current day only: a value before today's midnight is rejected with `400 Bad Request`, a value earlier today is accepted but the token is rejected right away. Pass a point in the future. Leave it `nil` for a token without expiry date. |
| `LastUsedDate` | *types.DateTime | When the token was last used for authentication. Server-managed, read-only. `nil` for a token that has never been used. |
| `Token` | string | The bearer token string. It is never sent back to the API, update and delete strip it from the request body. **NOTE: This value is visible only once, when creating a new API token. This information can't be accessed at a later point again.** |

## Create
To create a new API token send an APIToken object with a `Name` and `Enabled` set to `true`. `ExpiryDate` is optional. All other attributes are generated by the server and returned after a successful creation, including the `Token` string.

### Example
```go
token := &myrasec.APIToken{
    Name:    "CI deploy",
    Enabled: true,
    ExpiryDate: &types.DateTime{
        Time: time.Now().AddDate(0, 6, 0),
    },
}

t, err := api.CreateApiTokenContext(ctx, token)
if err != nil {
    log.Fatal(err)
}

// t.Token is shown only here, store it right away.
log.Println(t.ID, t.Name, t.Token)
```

## List
The listing operation returns the API tokens of the account you are accessing the API with.  
**NOTE: The tokens in this list do not contain the `Token` string. This value is visible only once, when creating a new API token.**

### Example
```go
tokens, err := api.ListApiTokensContext(ctx, nil)
if err != nil {
    log.Fatal(err)
}

for _, t := range tokens {
    log.Println(t.ID, t.Name, t.Enabled, t.ExpiryDate, t.LastUsedDate)
}
```

It is possible to pass a map of parameters (`map[string]string`) to the `ListApiTokensContext` function.

| name | description | default |
|---|---|---|
| `search` | Filter by the specified search query (matches the name). | null |
| `sort` | Sort by field and direction in the form `field:direction`, e.g. `name:asc`. Several fields can be separated by commas. | null |
| `page` | Specify the page of the result. | 1 |
| `pageSize` | Specify the amount of results in the response. | 50 |

## Update
Updating an API token needs the `ID` and `Modified` attributes to identify the object and verify the version. The update replaces `Name`, `Enabled` and `ExpiryDate` with the sent values, so pass every attribute that should be kept: an update without `ExpiryDate` clears the expiry date and an update with `Enabled` left `false` disables the token. Updating a token of another user is rejected with `403 Forbidden`. A token carrying the name the API reserves for internal use cannot be updated at all, neither renamed nor disabled, the API answers `400 Bad Request`; such a token can only be deleted.

### Example
```go
token := &myrasec.APIToken{
    ID: 0000,
    Modified: &types.DateTime{
        Time: modified,
    },
    Name:    "CI deploy (paused)",
    Enabled: false,
}

t, err := api.UpdateApiTokenContext(ctx, token)
if err != nil {
    log.Fatal(err)
}
```

## Delete
For deleting an API token it is only necessary to send the `ID` attribute. Deleting a token of another user is rejected with `403 Forbidden`.

### Example
```go
_, err := api.DeleteApiTokenContext(ctx, token)
if err != nil {
    log.Fatal(err)
}
```
